# Kyle Koyanagi Academic Website

A responsive static academic website designed for GitHub Pages.

## Publish at `kylekoyanagi.github.io`

1. Sign in to GitHub.
2. Create a new **public** repository named exactly:

   `kylekoyanagi.github.io`

3. Upload every file and folder from this package to the repository root.
4. Commit the files to the `main` branch.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, select **Deploy from a branch**.
7. Select the `main` branch and the `/ (root)` folder, then save.
8. After GitHub finishes deploying, the site will appear at:

   `https://kylekoyanagi.github.io`

## Email protection

The email address is not written as plain text in the HTML. JavaScript reconstructs it from character codes only when a visitor clicks the email button. This blocks many simple address-harvesting bots, although no public webpage can guarantee complete protection from sophisticated scraping.

## Update the site

- Main content: `index.html`
- Colours and layout: `styles.css`
- Email button and mobile menu: `script.js`
- Headshot: `assets/kyle-koyanagi-headshot.webp`

Replace files in the GitHub repository and commit the changes. GitHub Pages will redeploy automatically.
